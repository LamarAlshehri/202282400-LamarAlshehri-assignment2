# AI Usage Report

## Tools Used & Use Cases
During this assignment, I used AI tools such as ChatGPT and github copilot to support my development process.  
The tools were mainly used for:

- Getting suggestions for structuring HTML sections  
- Understanding how to implement responsive layouts using Flexbox and Grid  
- Clarifying how certain CSS properties work (e.g., aspect-ratio, object-fit)  
- Improving small JavaScript interactions such as the theme toggle and form behavior  
- Reviewing ideas for organizing documentation

AI served as a learning assistant and reference, similar to an interactive tutor.

---

## Benefits & Challenges

### Benefits
Using AI helped me:
- Start faster when I was unsure how to structure parts of the page  
- Discover cleaner or more efficient CSS techniques  
- Better understand how HTML, CSS, and JavaScript connect together  
- Debug issues more quickly by receiving explanations

### Challenges
Sometimes AI suggestions:
- Needed adaptation to match assignment requirements  
- Were more advanced than necessary for this level  
- Required simplification to keep the project clear and maintainable  

I had to carefully evaluate which suggestions were appropriate.

---

## Learning Outcomes
From using AI in this assignment, I improved my:

- Understanding of responsive web design  
- Ability to translate design ideas into code  
- Knowledge of how layout systems like Grid and Flexbox operate  
- Confidence in modifying and debugging generated code  

Most importantly, I learned how to use AI as a support tool rather than relying on it blindly.

---

## Responsible Use & Modifications
I did not copy AI outputs directly into the project without review.

Instead, I:
- Tested all suggestions  
- Modified structure and wording  
- Adjusted styles to match my design goals  
- Simplified solutions when necessary  
- Ensured I understood how each part worked  

All final decisions, edits, and organization of the project reflect my own understanding.

---

## Reflection
AI made the development process more efficient and educational.  
It helped me learn faster, but the responsibility for correctness, design choices, and final implementation remained mine.
